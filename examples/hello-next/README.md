# hello-next

A minimal Next.js App Router starter project for ATOMIC Studio.

## Structure

- `app/layout.tsx` — Minimal root HTML layout and metadata
- `app/page.tsx` — The main application page
- `app/globals.css` — Clean, dependency-light styles
- `components/Card.tsx` — Reusable interactive React client component

## Getting Started

### 1. Install dependencies

From the repository root (recommended):
```bash
npm install
```

Or within this folder:
```bash
cd examples/hello-next
npm install
```

### 2. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for production

```bash
npm run build
```

## Using with ATOMIC Studio

1. Open ATOMIC Studio.
2. Click **Open project** and select `examples/hello-next`.
3. Click **Run preview** in the top bar to launch the Next.js dev server.
4. Click **Select element** (or press the inspector shortcut) to click any element in the live preview and edit its source directly.
